# Restaurant Budget Finder

A Python project demonstrating how to retrieve, process and filter restaurant data using a REST API.

## Features

- Makes HTTP GET requests using Python's `requests` library.
- Parses JSON responses.
- Handles paginated API results.
- Filters food outlets by maximum estimated cost for two people.
- Preserves the original order of matching results.

## Technologies

- Python 3
- Requests
- REST APIs
- JSON

## Running the project

1. Install Python 3.
2. Install dependencies using `pip install -r requirements.txt`.
3. Run `python main.py`.
4. Enter a city and maximum budget when prompted.
